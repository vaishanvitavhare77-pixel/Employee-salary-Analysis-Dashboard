# Employee Salary Analysis Dashboard

## Project Overview

This project presents an interactive dashboard for exploring employee salaries, experience levels, and department-wise salary differences.

The dashboard uses Python, Pandas, and Plotly to transform employee data into interactive visualizations.

## Objectives

* Analyze salary patterns across departments.
* Explore the relationship between experience and salary.
* Understand the distribution of employee salaries.
* Compare salary variation between departments.
* Present data insights through interactive charts.

## Technologies Used

* Python
* Pandas
* NumPy
* Plotly
* HTML
* GitHub

## Visualizations

The dashboard includes six different chart types:

1. Bar chart
2. Line chart
3. Scatter plot
4. Histogram
5. Box plot
6. Correlation heatmap

The charts support interactive exploration through hover tooltips and Plotly's built-in chart controls.

## Dataset

The project uses 300 synthetic employee records generated with Python for educational and demonstration purposes.

The data does not represent actual employees or verified salary statistics.

## How to Run

Install the required libraries:

```bash
python -m pip install pandas plotly numpy
```

Generate the dataset:

```bash
python create_dataset.py
```

Run the exploratory analysis:

```bash
python eda_analysis.py
```

Generate the dashboard:

```bash
python dashboard.py
```

Open `employee_salary_dashboard.html` in a web browser with an internet connection.

## Project Outcome

The dashboard provides a visual way to explore employee salary patterns, compare departments, and investigate the relationship between experience and salary.
